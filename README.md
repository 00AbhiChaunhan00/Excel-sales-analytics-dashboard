# 📌 Project Overview

This project presents an **interactive Excel Sales & Analytics Dashboard** designed to transform raw sales data into meaningful business insights.

Using advanced Excel features such as **Pivot Tables, Pivot Charts, XLOOKUP, Conditional Formatting, Slicers, and VBA Automation**, the dashboard enables users to monitor sales performance, customer behavior, product trends, and delivery metrics through a clean and interactive interface.

The dashboard allows business users to quickly identify trends, compare KPIs, and make data-driven decisions without writing code.

---

# 🎯 Project Objective

The main objective of this project is to:

- Analyze overall sales performance
- Identify top-performing products
- Understand customer purchasing behavior
- Track occasion-wise sales
- Monitor order delivery performance
- Build an interactive dashboard for business decision-making

### Step 1

```bash

```

### Step 2

Open the Excel workbook.

### Step 3

Enable Macros.

### Step 4

Use slicers and filters to explore business insights.
