# Excel Sales & Analytics Dashboard

## Overview
An Excel-based Sales & Customer Analytics Dashboard designed to analyze sales performance, customer behavior, product trends, and delivery insights using Pivot Tables, charts, and dashboards.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- XLOOKUP
- VBA Macro

## Features
- Sales Analysis
- Occasion-wise Insights
- Product Performance Tracking
- Customer Analysis
- Dashboard Visualization
- Automated Dashboard Refresh

## Skills Demonstrated
- Data Cleaning
- Dashboard Creation
- Data Visualization
- Reporting & Analytics
- Business Insights

## Project Goal
To create an interactive business dashboard for analyzing sales data and generating actionable insights.
